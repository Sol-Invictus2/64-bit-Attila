64-BIT ATTILA
(version 1.3.27)

Bugs, crashes and logs: post them on Discord, https://discord.gg/3TUEGTMshP

Runs Total War: ATTILA as a 64-bit game on Windows, using the 64-bit game file Steam
offers for the Linux version. You need Total War: ATTILA on Steam, and Steam running.
Your normal Attila files and saves are not changed. After installing, Steam's Play button
  starts 64-bit Attila (the installer asks first).

HOW TO INSTALL (about 5 minutes)
  1. Double-click  Install 64-bit Attila.exe
     If a blue Windows box appears, click "More info", then "Run anyway".
  2. A black window opens, and Steam opens a page called CONSOLE.
  3. In Steam's CONSOLE page, click the long box at the very bottom.
  4. Press Ctrl+V, then press Enter. This tells Steam to download the 64-bit game file.
  5. Wait. The black window shows how far Steam's download is. After a few minutes
     Steam writes "Depot download complete", and the black window carries on by itself.
     Don't close it.
  6. The black window asks to set Steam's Play button to 64-bit Attila: press Enter.
     Steam closes for a moment and opens again.
  7. When the black window says "Done!", close it.
  8. Press Play on Attila in Steam, or use the new "64-bit Attila" icon on your desktop.

  If the CONSOLE page didn't open: press the Windows key + R, type  steam://open/console
  and press Enter.
  If Ctrl+V pastes nothing: type  download_depot 325610 325624  and press Enter.

FIRST START
  The first start can take a minute or more. A mod list opens: tick your mods and press
  Play. Click to skip the intro movie.

NEW IN 1.3.27  (fewer false crashes with overlays, HDR fix; thanks to ATN / RenoDX)
  - The game no longer closes when a graphics driver, ReShade or another overlay, or a
    Windows file hits a small error that it handles by itself. Real crashes are still
    caught and logged as before.
  - With an HDR mod (such as ReShade HDR) the frame-rate number and the Discord button
    show normally instead of a block of broken pixels.
  - The Discord button on the main menu can be turned off: put a line
    discord_button=off  in settings.txt in the attila64 folder.
  - Plugins that hook 12 to 15 bytes of the game no longer crash.
  - These three fixes were found and made by ATN (RenoDX). Thank you!
  - Players on 1.3.19 or newer get this version by themselves at the next start.

NEW IN 1.3.24  (smoother on PCs with fewer cores and on laptops)
  - The game's helper threads go to sleep at once again when they have no work, as in
    normal Attila. Keeping them awake gave no extra speed in tests but used much more
    processor time, which could slow down PCs with 4-6 cores and laptops.
  - To turn the old way back on, add the line  task_waits=fast  to attila64\settings.txt.
  - Players on 1.3.19 or newer get this version by themselves at the next start.

NEW IN 1.3.19  (updates itself from the Workshop)
  - 64-bit Attila now updates itself. When Steam has downloaded a newer version of this
    Workshop item, the next start of 64-bit Attila installs it (a small "Updating..." note
    shows for a few seconds) and then starts the new version. Your settings, mod list, the
    game file and Steam's Play button are not touched.
  - Only ever to a NEWER version. If Steam is still downloading, it waits for the next start.
    If anything goes wrong, the version you have starts as before.
  - To stop it: put an empty file named update_off.txt in the attila64 folder (the same
    switch stops the engine performance fix's updates).
  - This is the last time you need to run the installer by hand to update.

NEW IN 1.3.6  (text with NVIDIA graphics cards)
  - With DirectX 11 on an NVIDIA graphics card, every text in the game was a solid bar: menus,
    buttons, panels, everything. The game fills its letter pictures with a copy that DirectX 11
    does not allow. AMD cards do the copy anyway, NVIDIA cards skip it. 64-bit Attila now turns
    those letter pictures into a kind DirectX 11 lets the game copy into, on every card.
  - Tested on an AMD card set to skip those copies the way NVIDIA does: without the fix every
    text was a bar, with it the text is back. Not yet tried on a real NVIDIA card.
  - If you switched to OpenGL because of this (graphics=opengl_fallback in settings.txt),
    you can remove that line again.

NEW IN 1.3.5  (battle line of sight with DirectX 11)
  - With DirectX 11, units could not see each other in battle: enemies stayed invisible in
    the open until they ran into your units, and the AI could not see you either, so it
    did not attack. The game works out who sees whom on the graphics card, and with
    DirectX 11 that never finished. With DirectX 11 it is now worked out on the processor,
    with the game's own code. OpenGL is unchanged.
  - Tested in the game's benchmark battle: line of sight is updated about as often as
    with OpenGL, at about the same frame rate.
  - If you switched to OpenGL because of this (graphics=opengl_fallback in settings.txt),
    you can remove that line again.

NEW IN 1.3.2  (multiplayer campaign battles with 3 or more players)
  - With 3 or more human players, the players who are not in a battle no longer decide it.
    The game was made for 2 players: everyone who was not in the battle shared one choice,
    and it switched to auto-resolve by itself after 60 seconds (when the AI attacks, they
    never even see the window). With "Default battle resolution: Auto-resolve" in the lobby
    (the default), that overruled the player who chose to fight.
    Now the other players watch the battle by default and cannot auto-resolve it; only the
    players who fight choose between fighting and auto-resolve. Games with 2 players work
    as in normal Attila.
  - "Concede Defeat" in a multiplayer battle ends the battle again, as in normal Attila.
    Since 1.2 the battle went on with the AI leading your army, and when it finished every
    player was sent back to the Campaign Games list. A player who drops out of a battle is
    still replaced by the AI.
  - Tested with 3 copies of the game on one PC (1212AD): battles fought with both other
    players watching, one battle ended by its time limit and one conceded; each time all
    three came back to the campaign map together. Not yet tested with 4 or more players or
    over the internet.
  - Every player in a multiplayer game needs this same version.

PLAYING TOGETHER
  - Everyone must use this version, the same update. You will not see normal Windows
    Attila games.
  - Use the same mods in the same order. For a first test, press Tick none in the mod list.
  - One hosts: Battles > Multiplayer Battle > Host Battle. The others join.
  - For 8 vs 8 against the AI, use Multiplayer Battle > Host Battle and add AI players.
    Custom Battle (single player) is 4 against 4.
  - In Test 14 a player who joined a 16-player battle lobby where every place was already
    taken could crash. Test 19 and later have a fix that is not yet tested with real players,
    so to be safe, let your friends join first, then fill the other places with AI players.

GOOD TO KNOW
  - The game may still crash. If it does, start it again from the icon,
    press "Copy last log" in the mod list window and paste it on the Discord,
    https://discord.gg/3TUEGTMshP (or press "Show log file" and send the file
    attila64_log.txt). In multiplayer, the logs
    of both players help most.
  - The 8-player campaign and 8 vs 8 battles are new and only lightly tested.
  - Built-in Intel graphics can be very slow, above all on the first start.
  - Apart from that one-time copy of your graphics settings, settings made here are kept
    apart from normal Attila.
  - If something in the interface looks wrong, set Interface size to 100% in the mod list
    window, and please tell us what you saw.
  - Campaign saves from normal 32-bit Attila don't work here: 64-bit Attila has its own
    saves. Saving to Steam Cloud is switched off for now, and saves are not tested
    much yet.
  - DLL mods for the 32-bit game do not work here. Normal .pack mods should; mods with
    custom shaders may not.
  - Steam invites (joining a friend from the overlay) are not tested yet.

  From 1.3.19 on, 64-bit Attila updates itself when it starts (see NEW IN 1.3.19).
  From an older version: run the new installer and type 1 to update.
  To remove it: Windows Settings > Apps > 64-bit Attila > Uninstall, or double-click
  "Uninstall 64-bit Attila.exe" in the attila64 folder (1.3.22 and newer), or run the
  installer and type 2. Normal Attila stays as it was.
